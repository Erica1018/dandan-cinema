# Roadmap / 路线图

These are proposed directions, not shipped features or promised dates. 以下为计划方向，不代表已完成，也未承诺时间。

1. Fresh-install reports and physical TV acceptance for the public package. / 收集全新安装与公开版电视实机反馈。
2. Simplify first pairing and modernize Android target SDK. / 简化首次配对，升级 Android 目标版本。
3. Validate individual MCP hosts and local agent workflows. / 逐个验证 MCP 客户端与本机 Agent 流程。
4. Support more subtitle languages and improve media preparation guidance. / 增加字幕语言与媒体准备引导。
5. Consider opt-in source adapters with clear authorization, capability and failure reporting. / 探索可选来源适配器，明确授权、能力与失败状态。

The first release does not include a cloud service, automatic movie search, universal provider login, DRM support, or multi-user accounts. 首版没有云服务、自动搜片、通用平台登录、DRM 或多用户账号。

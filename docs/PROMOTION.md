# Launch drafts / 发布宣传草稿

Prepared for the owner. These have **not** been posted. 以下为作者准备的草稿，**尚未对外发布**。

## 中文首发草稿

我把自己做的「蛋蛋影院」开源了。

起点很简单：想看的内容先放进一个自己的片单，准备好以后，在电视上用遥控器打开。后来我也给它加了 Agent 接口，让助手能够帮忙收藏、整理和更新片单。

现在公开的是第一个预览版：中文和英文界面、Windows 端片单、Android TV 播放器，以及标准 MCP 和命令行接入。可以手动用，也可以尝试接自己的助手，不必和我用同一种。

它不附带影片，也不提供全网找片或会员绕过。第一次配置还需要按说明操作；公开版的设备兼容性也希望和第一批使用者一起验证。

源码、安装说明和已验证范围：[Dandan Cinema](https://github.com/Erica1018/dandan-cinema)

如果你愿意试用，最想听到的是：卡在哪一步、用什么电视、你希望 Agent 帮你完成哪一个具体动作。

## English launch draft

I open-sourced Dandan Cinema, a small personal watchlist and Android TV player I built for my own movie nights.

Save a title on your computer, prepare your own media, and open the same library with your TV remote. Optional stdio MCP and CLI tools let your own assistant help organize it. You can also use the library manually, without an AI account.

The first public preview includes English and Chinese interfaces, Windows setup instructions, and an Android TV APK. Setup still takes a few commands, and this public package needs broader device testing. It does not bundle films, bypass subscriptions or promise universal video-site support.

[Source, installation and verification notes](https://github.com/Erica1018/dandan-cinema)

I'd love early feedback on the setup steps, TV compatibility, and the specific library tasks you want an assistant to handle.

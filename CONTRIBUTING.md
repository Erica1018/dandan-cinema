# Contributing / 参与贡献

Issues and pull requests are welcome in English or Chinese. Start with the smallest reproducible problem or proposal. Include the release version, OS/TV model, what you expected, what happened and sanitized steps. Do not attach real libraries, film files, tokens or account sessions.

Read the shared [project protocol](AGENTS.md) and handoff. Preserve existing changes. Keep UI/docs bilingual, stable IDs, one shared API and deletion previews. Do not add analytics, public network binding, automatic downloads or unrelated dependencies without discussing the design. Use synthetic fixtures.

Run the checks in [BUILD.md](docs/BUILD.md). A media change needs evidence for that media path; a UI change should be inspected in both languages. Clearly identify whether an outcome was a unit test, browser test, build or physical-device check. By contributing, you agree your contribution may be distributed under this repository's MIT license.

中文：欢迎中文或英文 Issue/PR。说明版本、设备、预期、实际结果与可复现步骤，使用脱敏资料。遵守共享项目协议，保留既有修改，保持中英同步、稳定 ID、统一接口和删除预览。按编译文档验证，区分自动测试、浏览器检查、构建与真实设备结果。提交贡献即同意以仓库 MIT 协议分发该贡献。
